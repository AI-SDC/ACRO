ACRO changelog#

Detailed ACRO version history, with the newest releases first. For announcements covering the tools together, visit SACRO Tools News.

Version 1.1.0 (Nov 05, 2026)#

Additional Functionality#

  • Add command shortcuts and factor notation in Stata. (#423, #427)

  • Add Cox proportional hazards regression support in Python and Stata. (#419, #422)

  • Add disclosure risk explanations. (#428)

Chore#

  • Bump the version number to 1.1.0. (#430)

Fix#

  • Correct the MyBinder link. (#417)

  • Include custom outputs in XLSX finalisation. (#418)

  • Join index conditions with & to avoid TypeError. (#415)

Version 1.0.1 (Aug 10, 2026)#

Additional Functionality#

  • Add pie chart support. (#355)

  • Add rounding as a protection mechanism. (#381)

  • Create and enforce a blocked file extension list for custom outputs. (#377)

  • Flag histogram bin-edge disclosure risks. (#192, #382)

  • Make ACRO ontology-driven. (#395)

Chore#

  • Add type hints. (#343)

  • Bump the version number to 1.0.1.

  • Clean up notebooks and folders. (#336)

  • Include the required JSON files in the acro package data and correct its pyproject.toml configuration.

  • Update GitHub Actions dependencies, including codecov/codecov-action from version 5 to 6. (#356, #374)

  • Update pre-commit hooks. (#333, #366, #372, #375, #385, #388)

  • Update Ruff configuration: enable 11 additional rule sets, ignore D213 because it conflicts with D212, and remove extend-ignore; remove unused pylint inline pragmas. (#371, #373)

CI#

  • Run tests on pull requests without running them twice. (#368)

Documentation#

  • Automate changelog generation from pull request names. (#352)

  • Replace pre-commit with prek in the contributing guide, update the guide, and add an AI policy. (#338, #369)

  • Update documentation and simplify examples. (#334)

  • Update the Stata cheat sheet. (#354)

Fix#

  • Correct cell ID misalignment and hierarchical reindexing. (#367)

  • Correct the README Python notebook link. (#359)

  • Handle invalid aggregation functions in Stata. (#365)

  • Honor zeros_are_disclosive when checking empty histogram bins. (#308, #386)

  • Resolve shape mismatches in crosstab and pivot_table with aggregation functions. (#347)

Refactoring#

  • Extract the acro_artifacts folder name into the ARTIFACTS_DIR constant. (#376)

  • Use dynamic column names in rounded_survival_table. (#332)

Additional Functionality#

  • Add setters to toggle suppression (#326)

  • Add support for init options in Stata (#320)

  • Make finalise non-interactive by default (#309)

CI#

Documentation#

  • Add documentation (#273, #287, #288, #289, #291, #304, #306, #318)

Fix#

  • Handle spaces in variable names for crosstab (#321)

  • Update summary status logic to reflect suppression state (#317)

Testing#

  • Add test for rounded_survival_table function in survival analysis (#324)

Version 0.3.0 (Jul 04, 2023)#

Additional Functionality#

Version 0.2.0 (Jun 28, 2023)#

Additional Functionality#

  • Add status, type and properties to the output metadata (#89)

  • Automatically copy custom outputs to the outputs folder upon finalise (#89)

  • Change output field in JSON to a list of file paths (#89)

  • Finalise now takes two arguments: path and ext to specify a folder (#89)

  • ISO format timestamps (#89)

  • Make custom file paths relative instead of absolute (#89)

  • Remove automatic reloading of existing results (#89)

  • Remove the timestamp from the output naming (#89)

  • Serialize JSON outcome field as a dictionary instead of string (#88)

  • Split statsmodels outputs into multiple csv files (#89)

  • Store comments as a list of strings (#89)

Fix#

  • Fix a bug attempting to write custom outputs in excel (#89)

Refactoring#

  • Major code refactor of output storage (#89)
